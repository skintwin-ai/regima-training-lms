
# Ingredients Reference Feature

The ingredients reference provides a comprehensive catalog of skincare ingredients used in REGIMA products, allowing users to search, filter, and learn about various active ingredients.

## Search and Filtering

- **Search Bar**: Allows users to search by ingredient name, function, or category
- **Category Filter**: Sidebar with clickable category buttons to filter ingredients
- **Filter Indicators**: Visual badges showing active filters with clear options

## Ingredient Display

- **Accordion Layout**: Expandable entries for each ingredient
- **Basic Information**: Name and category of each ingredient
- **Detailed View**: When expanded, shows:
  - Concentration range
  - Main functions
  - Skin benefits
  - REGIMA formulation notes

## Organization

- **Category Sidebar**: Organizes ingredients by type (REGIMA Proprietary Actives, Exfoliants, etc.)
- **Scrollable Content Areas**: Supports browsing large lists of ingredients
- **Count Indicators**: Shows number of ingredients matching current filters

## Integration

- Link to related training modules
- Cross-referencing with product formulations
- Educational context about ingredient science
