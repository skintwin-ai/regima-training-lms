
# Products Catalog Feature

The products catalog provides a searchable and filterable database of REGIMA skincare products for both retail and professional use.

## Search and Filtering System

- **Search Functionality**: Search by product name, description, ingredients, or skin types
- **Type Filters**: Toggle between Professional and Retail product types
- **Category Filters**: Browse products by category (Cleansers, Exfoliants, Serums, etc.)
- **Filter Indicators**: Visual badges showing active filters with clear options

## Product Display

- **Accordion Layout**: Expandable entries for each product
- **Basic Information**: Product name, size, and type at a glance
- **Detailed View**: When expanded, shows:
  - Full description
  - Key ingredients
  - Recommended skin types
  - Usage instructions

## Organization

- **Category Navigation**: Left sidebar with product categories
- **Type Filtering**: Visual icons distinguishing between professional and retail products
- **Visual Indicators**: Badges showing product type and category

## Empty State Handling

- Clear messaging when no products match search/filter criteria
- Option to clear all filters
- Suggestions for alternative search approaches

## Cross-References

- Links to the Ingredients Reference for detailed ingredient information
- Educational context for product application
