
# Modules Feature

The modules page displays all available training modules in the REGIMA skincare training curriculum and provides detailed views of individual modules.

## Module List View

- **Progress Indicator**: Visual representation of overall training completion
- **Module Cards**: Each card displays:
  - Module title and description
  - Estimated completion time
  - Completion status (completed, unlocked, or locked)
  - Status indicators and badges
  - Start/Review button based on completion status

## Module Detail View

When a specific module is selected, users can see:
- Module header with title and description
- Estimated completion time
- List of lessons within the module
- Lesson status indicators (completed, ready to start, or locked)
- Navigation to start individual lessons

## Progressive Unlocking System

- First module is automatically unlocked for new users
- Subsequent modules are unlocked only after completing previous modules
- Visual indicators clearly show which modules are available

## Navigation

- Back button to return to module list
- Direct links to start or review lessons
- Conditional rendering based on user progress
