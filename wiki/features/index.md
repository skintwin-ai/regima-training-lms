
# REGIMA Training Platform Features

The REGIMA skincare training platform is a comprehensive web application designed to provide professional education for skincare specialists. The application includes several key features:

## Core Features

- [Dashboard](./dashboard.md) - The central hub showing user progress and available modules
- [Modules](./modules.md) - Structured training units with sequential lessons
- [Lessons](./lesson.md) - Individual training content with videos, text, and interactive elements
- [Ingredients Reference](./ingredients.md) - Comprehensive catalog of skincare ingredients
- [Products Catalog](./products.md) - Database of professional and retail skincare products

## Platform Systems

- [Authentication](./authentication.md) - User login and session management
- [Progress Tracking](./progress-tracking.md) - System for monitoring user advancement

## Technical Architecture

The platform is built with:
- React frontend with TypeScript
- Express.js backend
- Session-based authentication
- React Query for API data fetching
- Shadcn UI component library

The application follows a responsive design approach to support both desktop and mobile users.
