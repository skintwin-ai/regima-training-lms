
# Dashboard Feature

The dashboard serves as the central hub for users of the REGIMA skincare training platform. It provides an overview of the user's progress, achievements, and quick access to training modules.

## Key Components

- **Welcome Header**: Personalized welcome message with the user's name
- **Course Progress Card**: Visual progress indicator showing completion percentage of training modules
- **Achievements Card**: Display of earned certificates and accomplishments
- **Profile Card**: Quick access to user profile information
- **Current Modules Section**: List of modules the user is currently working on
- **Upcoming Modules Tab**: Modules that will be unlocked as the user progresses
- **Completed Modules Tab**: History of modules the user has finished

## User Authentication

The dashboard includes a login form for unauthenticated users with:
- Username and password fields
- Login button with loading state
- Demo credentials for testing purposes

## Responsive Design

The dashboard is fully responsive with:
- Sidebar navigation for desktop view
- Mobile header with menu toggle for mobile view
- Adaptive card layouts for different screen sizes
