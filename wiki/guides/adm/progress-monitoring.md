
# Progress Monitoring

This guide explains how administrators and trainers can monitor student progress through the REGIMA Training Platform.

## Accessing Progress Data

1. Log in with your administrator credentials
2. Navigate to the Admin Dashboard
3. Select "Progress Monitoring" from the main menu

## Overview Dashboard

The Progress Overview dashboard provides a high-level summary:

- **Overall Completion Rate**: Percentage of all users who have completed the full curriculum
- **Active Users**: Number of users who logged in within the last 30 days
- **Completion by Module**: Bar chart showing completion rates for each module
- **Average Time to Completion**: Typical time users take to complete the curriculum

## User Progress Reports

### Viewing Individual Progress
1. Navigate to "User Progress" in the Progress Monitoring section
2. Search for a user by name, email, or ID
3. Select a user to view their detailed progress report:
   - Overall completion percentage
   - Modules completed with dates
   - Lessons completed with dates
   - Quiz scores
   - Time spent on each module
   - Notes and feedback submitted

### Batch Progress Reports
1. Go to "Batch Reports" in the Progress Monitoring section
2. Filter users by:
   - Registration date
   - Organization
   - Completion status
   - Activity level
3. Click "Generate Report"
4. View the report on screen or export to CSV/PDF

## Progress Analytics

The analytics section provides deeper insights:

### Engagement Metrics
- **Session Duration**: Average time users spend in training sessions
- **Completion Rate**: Percentage of started modules that get completed
- **Drop-off Points**: Lessons where users commonly stop progressing

### Performance Metrics
- **Quiz Performance**: Average scores on knowledge checks
- **Retry Rate**: How often users need to retake quizzes
- **Difficulty Analysis**: Identifies questions with low success rates

## Intervention Tools

### Progress Alerts
1. Set up automatic alerts for:
   - Users who haven't logged in for X days
   - Users stuck on a specific module for X days
   - Users who fail a quiz multiple times
2. Configure notification methods (email, dashboard, etc.)

### Direct Assistance
1. From a user's progress page, click "Contact User"
2. Choose from template messages or write a custom message
3. Send encouragement, tips, or offer additional resources

### Bulk Actions
1. Select multiple users based on progress filters
2. Choose an action:
   - Send group message
   - Assign additional resources
   - Reset progress on specific lessons
   - Extend certification deadlines

## Certification Tracking

Monitor users approaching certification:
1. Go to "Certification Tracking" in the Progress Monitoring section
2. View users who have:
   - Completed all requirements
   - Are within 90% of completion
   - Have certifications expiring soon
3. Issue certificates or renewal reminders as needed

## Reporting Best Practices

- Review the Progress Overview dashboard weekly
- Check for users with stalled progress monthly
- Analyze quiz performance quarterly to identify content that may need improvement
- Follow up personally with users who are close to certification
- Use progress data to inform content revisions
