
# Content Administration

This guide covers how to manage training content in the REGIMA Training Platform as an administrator or trainer.

## Content Structure Overview

The REGIMA platform organizes training content in a hierarchical structure:

```
Curriculum
└── Modules
    └── Lessons
        ├── Video Demonstrations
        ├── Text Content
        ├── Knowledge Checks
        └── Resources
```

## Accessing the Content Management System

1. Log in with your administrator credentials
2. Navigate to the Admin Dashboard
3. Select "Content Management" from the main menu

## Managing Modules

### Creating a New Module
1. From the Content Management section, click "Add New Module"
2. Fill in the required fields:
   - Module Title
   - Description
   - Estimated Completion Time
   - Cover Image (upload)
   - Prerequisites (select existing modules if applicable)
3. Click "Create Module"

### Editing Existing Modules
1. Find the module in the module list
2. Click the "Edit" button
3. Update any field as needed
4. Click "Save Changes"

### Module Sequencing
1. Go to "Module Sequence" in the Content Management menu
2. Drag and drop modules to reorder them
3. Click "Save Sequence" to apply changes

## Managing Lessons

### Creating a New Lesson
1. Navigate to the parent module
2. Click "Add New Lesson"
3. Fill in the required fields:
   - Lesson Title
   - Video URL (YouTube or Vimeo)
   - Technique Overview (rich text editor)
   - Key Benefits (bullet points)
   - Step-by-Step Procedure
4. Add images for the practical demonstration section
5. Fill in the common mistakes section
6. Click "Create Lesson"

### Editing Existing Lessons
1. Find the lesson within its module
2. Click the "Edit" button
3. Update any field as needed
4. Click "Save Changes"

### Lesson Sequencing
1. Go to the parent module
2. Click "Manage Lesson Sequence"
3. Drag and drop lessons to reorder them
4. Click "Save Sequence"

## Creating Knowledge Checks

1. Navigate to the lesson you want to add a quiz to
2. Click "Add Knowledge Check"
3. For each question:
   - Enter the question text
   - Add multiple choice options
   - Mark the correct answer(s)
   - Add feedback for correct and incorrect responses
4. Set the passing score (default is 70%)
5. Click "Save Knowledge Check"

## Managing Resources

### Adding Resources to Lessons
1. Navigate to the lesson
2. Scroll to the "Resources" section
3. Click "Add Resource"
4. Select the resource type:
   - PDF Document
   - Video
   - Checklist
   - Link
5. Upload or link the resource
6. Add a title and description
7. Click "Add Resource"

## Content Preview and Testing

Before publishing new content:
1. Click the "Preview" button on any lesson or module
2. Test all interactive elements
3. Verify that videos play correctly
4. Complete the knowledge check as a student would
5. Test navigation between lessons

## Publishing Content

1. When content is ready, set the "Publication Status" to "Published"
2. Choose whether to notify users about the new content
3. Click "Publish"

## Content Maintenance Best Practices

- Review content regularly for accuracy and relevance
- Update product information when formulations change
- Incorporate student feedback to improve clarity
- Keep video demonstrations current with latest techniques
- Check all links and downloadable resources quarterly
