
# Completing Modules

Modules are the core training units of the REGIMA skincare training curriculum. This guide will help you navigate and complete modules effectively.

## Understanding Modules

Each module in the REGIMA training platform represents a complete training unit focused on a specific skincare topic or technique. Modules contain multiple lessons that build upon each other.

## Module List View

When you visit the Modules page, you'll see:

### 1. Overall Progress Indicator
At the top of the page, a progress bar and text show your overall completion status across all modules:
- Progress percentage
- "X of Y modules completed" counter

### 2. Module Cards
Each module is represented by a card containing:
- **Module Title**: The name of the training unit
- **Description**: Brief overview of what you'll learn
- **Estimated Completion Time**: How long the module typically takes to complete
- **Status Indicator**: Shows if the module is completed, in progress, or locked
- **Action Button**: "Start," "Continue," or "Review" depending on your progress

## Module Status Types

Modules will display one of these statuses:

- **Completed**: You've finished all lessons and assessments in this module
- **In Progress**: You've started but not completed this module
- **Locked**: This module is not yet available (requires completion of previous modules)

## Progressive Unlocking

The REGIMA platform uses a progressive unlocking system:
- Your first module is automatically unlocked when you start
- Additional modules are unlocked only after you complete previous modules
- This ensures you build your skills in the proper sequence

## Accessing Module Content

1. Click on an unlocked module card
2. You'll see the Module Detail View with:
   - Module title and description
   - List of lessons within the module
   - Status indicators for each lesson
   - Navigation buttons to start lessons

## Completing a Module

To complete a module:
1. Finish each lesson in sequence
2. Complete all knowledge checks and assessments
3. The system will automatically mark the module as complete
4. This will unlock the next module in the curriculum

## Tips for Success

- Complete modules in the recommended order
- Don't skip lessons within a module - each builds on the previous content
- Use the estimated completion time to plan your training sessions
- Review completed modules before assessments for better retention
