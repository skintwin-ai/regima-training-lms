
# Content Administration Tutorial

## Introduction

This tutorial will guide you through managing the training content in the REGIMA platform as an administrator or trainer.

## Accessing the Content Management System

1. Open your web browser and navigate to the REGIMA Training Platform
2. Log in with your administrator credentials
3. Navigate to the Admin Dashboard
4. Select "Content Management" from the main menu

## Managing Modules

### Creating a New Module

![Creating a Module](https://example.com/create-module.jpg)

1. From the Content Management section, click "Add New Module"
2. Fill in the required fields:
   - **Module Title**: Enter a descriptive title (e.g., "Facial Massage & Lymphatic Drainage")
   - **Description**: Write a concise overview of what trainees will learn
   - **Estimated Completion Time**: Specify how long the module will take (e.g., "60 minutes")
   - **Cover Image**: Upload an image that represents the module content
   - **Prerequisites**: Select existing modules if this one requires prior knowledge
3. Click "Create Module"

**Practice**: Create a test module with a title starting with "TEST-" to see how the process works.

### Editing Existing Modules

1. Find the module in the module list
2. Click the "Edit" button
3. Update any field as needed
4. Click "Save Changes"

### Module Sequencing

Proper sequencing ensures trainees complete modules in the correct order:

1. Go to "Module Sequence" in the Content Management menu
2. You'll see all modules in their current order
3. Drag and drop modules to reorder them
4. Click "Save Sequence" to apply changes

**Practice**: Adjust the order of your test module to see how sequencing works.

## Managing Lessons

### Creating a New Lesson

![Creating a Lesson](https://example.com/create-lesson.jpg)

1. Navigate to the parent module
2. Click "Add New Lesson"
3. Fill in the required fields:
   - **Lesson Title**: Enter a descriptive title
   - **Video URL**: Paste a YouTube or Vimeo URL for the demonstration
   - **Technique Overview**: Use the rich text editor to explain the technique
   - **Key Benefits**: Add bullet points highlighting the benefits
   - **Step-by-Step Procedure**: Create numbered steps for the procedure
4. Add images for the practical demonstration section:
   - Click "Add Image"
   - Upload an image or select from the media library
   - Add a caption explaining what the image shows
5. Fill in the common mistakes section to help trainees avoid errors
6. Click "Create Lesson"

**Practice**: Add a test lesson to your test module.

### Editing Existing Lessons

1. Find the lesson within its module
2. Click the "Edit" button
3. Update any field as needed
4. Click "Save Changes"

### Lesson Sequencing

1. Go to the parent module
2. Click "Manage Lesson Sequence"
3. Drag and drop lessons to reorder them
4. Click "Save Sequence"

## Creating Knowledge Checks

Knowledge checks ensure trainees understand key concepts:

1. Navigate to the lesson you want to add a quiz to
2. Click "Add Knowledge Check"
3. For each question:
   - Enter the question text in the "Question" field
   - Add multiple choice options (minimum of 3, maximum of 5)
   - Mark the correct answer(s)
   - Add feedback for correct and incorrect responses
4. Set the passing score (default is 70%)
5. Click "Save Knowledge Check"

**Practice**: Create a 3-question knowledge check for your test lesson.

## Managing Resources

### Adding Resources to Lessons

1. Navigate to the lesson
2. Scroll to the "Resources" section
3. Click "Add Resource"
4. Select the resource type:
   - PDF Document
   - Video
   - Checklist
   - Link
5. Upload or link the resource
6. Add a title and description
7. Click "Add Resource"

## Content Preview and Testing

Before publishing new content:

1. Click the "Preview" button on any lesson or module
2. Test all interactive elements
3. Verify that videos play correctly
4. Complete the knowledge check as a student would
5. Test navigation between lessons

## Publishing Content

When content is ready for trainees:

1. Set the "Publication Status" to "Published"
2. Choose whether to notify users about the new content
3. Click "Publish"

## Content Maintenance Best Practices

- Review content regularly for accuracy and relevance
- Update product information when formulations change
- Incorporate student feedback to improve clarity
- Keep video demonstrations current with latest techniques
- Check all links periodically to ensure they still work
