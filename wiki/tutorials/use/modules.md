
# Working with Modules Tutorial

## Introduction

Modules are the core training units in the REGIMA platform. This tutorial will show you how to navigate, understand, and complete modules effectively.

## Accessing the Modules Page

1. Log in to your REGIMA Training Platform account
2. Click "Modules" in the main navigation sidebar
3. You'll see a list of all available training modules

## Understanding the Module List

The module list displays all training modules with important information:

![Module List View](https://example.com/module-list.jpg)

1. **Progress Indicator**: At the top, shows your overall completion progress
2. **Module Cards**: Each card contains:
   - Module title
   - Description summarizing what you'll learn
   - Estimated completion time
   - Status indicator (Completed, In Progress, or Locked)
   - Action button to start, continue, or review the module

## Module Status Types

You'll notice different statuses for modules:

- **Completed** (Green checkmark): You've finished all lessons and assessments
- **In Progress** (Blue indicator): You've started but not completed this module
- **Locked** (Gray with lock icon): Not yet available - requires completion of previous modules

## Starting a Module

1. Find an unlocked module in the list
2. Click the "Start" button (or "Continue" if you've already begun)
3. You'll be taken to the module detail page showing:
   - Module title and description
   - List of lessons within the module
   - Status indicators for each lesson
   - Navigation buttons to start individual lessons

## Progressing Through a Module

The REGIMA platform uses progressive unlocking:

1. Complete each lesson in sequence
2. Each lesson must be fully completed (video, content, quiz) to be marked as done
3. When a lesson is completed, the next one automatically unlocks
4. After completing all lessons, the module is marked as complete
5. This unlocks the next module in your training sequence

## Viewing Your Progress

To check your module progress:

1. The dashboard shows your overall completion percentage
2. On the Modules page, completed modules show a green checkmark
3. In-progress modules show which lessons are completed and which remain

## Practice Exercise

Try these steps to practice working with modules:

1. Navigate to the Modules page
2. Identify which module you're currently working on
3. Click on that module to see its lessons
4. Resume your training by clicking on the next unlocked lesson

## Tracking Completion

The system automatically tracks your progress. A module is considered complete when:

1. You've viewed all video content
2. You've read through all lesson materials
3. You've successfully passed all knowledge checks
